# Bewerbungs-Tracker

Ein einfacher, lokaler Bewerbungs-Tracker als einzelne HTML-Datei. Keine Installation nötig — einfach im Browser öffnen.

## Funktionen

- Stellenangebote hinzufügen, bearbeiten und löschen
- Status verfolgen: Neu, Entwurf fertig, Beworben, Vorstellungsgespräch, Abgelehnt
- Arbeitsmodell: Remote, Hybrid, Vor Ort
- Notizen pro Stelle
- Excel-Export und -Import (via SheetJS)
- Daten werden lokal im Browser gespeichert (localStorage)

## Nutzung

**Online:** Öffne die GitHub Pages-Seite direkt im Browser.

**Offline:** Lade `index.html` herunter und öffne die Datei in einem beliebigen Browser.

## Hinweise

- Daten bleiben pro Browser gespeichert — beim Wechsel des Browsers oder Computers den Excel-Export nutzen.
- Keine Registrierung, kein Server, keine Kosten.
